# Retail Segments in Glasgow

An interactive web map exploring how supermarket provision varies across Glasgow by retail segment (budget, mid, upper-mid and premium).

**Live map:** https://adiandian315.github.io/glasgow-retail-map/

## Features
- Segment slider to move between budget, mid, upper-mid and premium retailers
- Heatmaps and store points styled by segment
- Store search by name
- 1 km proximity search: click anywhere on the map to see stores within 1 km (Turf.js buffer)

## Tools
Mapbox GL JS, Mapbox Studio, Turf.js, HTML, CSS and JavaScript

## Data
Supermarket locations from GEOLYTIX Retail Points (open data). Basemap © Mapbox © OpenStreetMap.

Built as part of the MSc Geoinformation Technology and Cartography, University of Glasgow.
